# TimeTaker: Einrichtung / Setup

**Link:** https://steinerfabian0.github.io/TimeTaker/app/

## Deutsch

**Du brauchst:** einen Laptop mit Windows 10/11 oder macOS und **Google Chrome**
oder **Microsoft Edge** (unter Windows schon vorhanden). Kein GitHub-Konto,
keine Installation von Treibern.

**Einmalig einrichten (mit Internet):**

1. Den Link oben in Chrome oder Edge öffnen.
2. In der Adressleiste rechts auf **„App installieren“** klicken (Symbol:
   Bildschirm mit Pfeil). Danach gibt es ein TimeTaker-Symbol auf dem Desktop
   bzw. im Startmenü / Dock.
3. TimeTaker über dieses Symbol starten. Ab jetzt läuft die App **ohne
   Internet**.

**Zeitnehmer verbinden:**

- **USB:** Kabel einstecken, in TimeTaker **Status → USB verbinden**, im
  Fenster „TimeTaker“ wählen. Beim nächsten Start verbindet sich die App von
  selbst.
- **Bluetooth:** **Status → Bluetooth verbinden**, „TimeTaker“ wählen. macOS
  fragt beim ersten Mal, ob Chrome Bluetooth benutzen darf: erlauben. Nach
  einem Neustart der App muss man meist noch einmal auf „Bluetooth verbinden“
  klicken.

**Gut zu wissen:**

- Während eines Grand Prix bleibt der Bildschirm an, damit der Laptop nicht
  einschläft. Trotzdem am besten ans Netzteil.
- **Sicherung:** Einstellungen → Daten → **Exportieren** speichert Rennvorlagen,
  Turniere und Autosätze als Datei. Mit **Importieren** kommen sie zurück (auch
  auf einen anderen Laptop).
- **Updates** kommen von selbst: Wenn TimeTaker mit Internet geöffnet wird,
  lädt es eine neue Version im Hintergrund und nutzt sie beim nächsten Start.
- Firefox, Safari und iPad/iPhone können den Zeitnehmer nicht ansprechen.

## English

**You need:** a laptop with Windows 10/11 or macOS and **Google Chrome** or
**Microsoft Edge** (already on Windows). No GitHub account, no drivers.

**One-time setup (with internet):**

1. Open the link above in Chrome or Edge.
2. In the address bar, click **"Install app"** (icon: a screen with an
   arrow). You now have a TimeTaker icon on the desktop / start menu / dock.
3. Start TimeTaker from that icon. From now on it works **without internet**.

**Connect the time taker:**

- **USB:** plug in the cable, then in TimeTaker **Status → Connect USB** and
  pick "TimeTaker". Next time it reconnects by itself.
- **Bluetooth:** **Status → Connect Bluetooth**, pick "TimeTaker". The first
  time, macOS asks whether Chrome may use Bluetooth: allow it. After the app
  restarts you usually need to click "Connect Bluetooth" once more.

**Good to know:**

- During a Grand Prix the screen stays on so the laptop does not fall
  asleep. Still, plug in the charger.
- **Backup:** Settings → Data → **Export** saves race presets, tournaments and
  car presets to a file; **Import** brings them back (also on another laptop).
- **Updates** arrive by themselves: when TimeTaker is opened with internet, it
  fetches a new version in the background and uses it from the next start.
- Firefox, Safari and iPad/iPhone cannot reach the time taker.
